# Testler

Her şeyi tek bir komutla çalıştır:

```bash
bash tests/run_all.sh     # 50/50 controls, ~20 s on a laptop; CI runs it on every push
```

## Adversarial denetimler ve benchmark (CI-barındırmalı)

- `tests/audit7_embedded_chain.py` — gömülü-zincir saldırıları (A1 splice zayıf/güçlü,
  A2 tip-swap, A3 merkle-fold): simnet, wasmtime yok; F25/F24 belgelenmiş sınırlar.
- `tests/audit8_node_cosign.py` — düğüm-ortak-imza (node-cosign) katmanı testleri (L1, F25'i kapatır).
- `tests/bench_runner_overhead.py` — runner-tarafı yük medyanları (yalnız-kanıt, geçme/kalma yok).
- `tools/check_links.py` — markdown bağıl-hedef bütünlüğü (0 kırık).

Yalnız-yerel adversarial araçlar (CI-barındırmalı değil: `tests/simnet/` altındaki,
gitignore'a alınmış simnet düğüm fixture (demir-örnek) dosyalarına bağımlılar):
`tests/simnet/f21_truncate.py` (defter-uca geri-sarma saldırısı) ve
`tests/simnet/merkle_tamper.py` (merkle tahrifatı); ikisi de runner saldırıyı
reddettiğinde 0 çıkış verir. Yavaş takım (`RUN_SLOW=1 bash tests/run_all.sh`) c30
çapraz-istem wall kontrolünü, AT-019'u (yayımlanmış-wheel nacl-engelli doğrulama),
AT-020'yi (self-pilot) ve AT-026'yı (wheel tam-modül) ekler — AT-021/022/023/024/025/027/028/029/030
50-kontrollük hızlı tabanda koşulsuz koşar. Hızlıda 50/50, RUN_SLOW=1 ile 55/55.
AT-027 (epoch-verify) 2026-09-13'te hızlı tabana katıldı (kontrol-51 yuvası; çevrimdışı-deterministik).
